Como verificamos os links e os apps

Metodologia do Baixa Certa: fonte primária, checagem de HTTP, versão datada, licença gratuita e aviso de instalador com ofertas.

Portal de download só presta se o link for confiável. Este é o ritual que cada app passa antes de aparecer no catálogo — e que se repete nas revisões periódicas.

1. Só fonte primária

O link de download tem que sair do domínio do próprio projeto (ex.: videolan.org, libreoffice.org, obsproject.com). Agregadores, blogs, espelhos e "repositórios de programas" ficam de fora, mesmo quando aparecem primeiro na busca.

2. Checagem do link

Cada botão é testado a partir do servidor: sigo os redirecionamentos e confirmo o código HTTP final e o tipo do arquivo. Quando o fabricante publica só uma página com formulário (caso do DaVinci Resolve) ou um redirecionamento dinâmico, o botão aponta para essa página oficial — e não para um espelho.

3. Versão e data

A ficha do app mostra a versão conferida, o tamanho do instalador e a data da última verificação. O catálogo é regenerado a partir de uma planilha de dados, então essas informações ficam sempre visíveis e datadas.

4. Grátis de verdade

Entra app com versão gratuita de uso real: open source ou freeware sem prazo. Programas com limite aparecem com a condição escrita na ficha ("grátis para uso pessoal", "versão gratuita com recursos limitados"). Trial de 30 dias não entra.

5. Reputação do instalador

Se o instalador oficial oferece programas extras, telemetria agressiva ou conta obrigatória, isso vai escrito no aviso da página — antes do botão. É o caso do instalador do FileZilla, que costuma sugerir software adicional na instalação.

6. Manutenção ativa

Projeto abandonado, sem atualização de segurança, não entra. Se um app listado parar de receber atualizações ou mudar de licença, ele sai do catálogo.

7. Apps de celular (Android)

Para celular, o link preferido é o APK publicado pelo próprio desenvolvedor (site oficial, GitHub ou F-Droid); quando o app só existe na loja, usamos a página oficial na Google Play. Nenhum APK vem de APKPure, APKMirror, Uptodown ou espelho. A ficha do app avisa sobre anúncios, compras dentro do app, conta obrigatória e permissões sensíveis — e vale a mesma regra: grátis de verdade, com a condição escrita.

O que este site não faz

Não hospeda arquivo. Não existe cópia no nosso servidor, não existe espelho, não existe "download alternativo". O clique vai direto ao fabricante.

Não modifica instalador. Nada de repack, nada de "versão otimizada", nada de instalador silencioso.

Não pede nada em troca. Sem cadastro, sem e-mail, sem cookie de rastreamento.

Encontrou link quebrado?

Me avise pelo contato com o nome do app. Corrijo e atualizo a data de verificação. Se o fabricante aposentou a versão gratuita, o app sai do catálogo.
