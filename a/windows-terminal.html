Windows Terminal

por Microsoft

Terminal oficial do Windows com abas, painéis divididos, perfis para PowerShell, CMD e WSL e interface personalizável.

O Windows Terminal é o terminal oficial da Microsoft: junta PowerShell, Prompt de Comando, WSL e Azure Cloud Shell em abas, com painéis divididos e renderização moderna. Serve para quem usa linha de comando todo dia, porque substitui várias janelas do console antigo por uma só, com busca, atalhos e temas. É gratuito e de código aberto, e já vem instalado no Windows 11. No Windows 10, instala pela Microsoft Store.
