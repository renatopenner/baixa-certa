Angry IP Scanner

por Angry IP Scanner (projeto open source)

Varre a rede local e lista IPs ativos, portas abertas, MAC e hostname, com exportação dos resultados.

O Angry IP Scanner varre faixas de IP da rede local e mostra quais endereços estão ativos, com portas abertas, nome do host, fabricante do MAC e tempo de resposta. Serve para descobrir aparelhos conectados no roteador, achar impressoras e câmeras, diagnosticar conflito de IP e documentar a rede. Exporta para CSV, TXT, XML e SQL, tem versão portátil e roda em Windows, macOS e Linux.

Requisitos

Windows 10/11 64 bits (o instalador já traz o Java)
Antes de instalar: O instalador para Windows inclui o Java necessário; existe também versão menor sem JRE para quem já tem Java instalado, além de .zip portátil. Alguns antivírus sinalizam scanners de porta por heurística — o projeto é open source e assinado. Use apenas em redes que você administra.
