Minecraft Launcher

por Mojang Studios (Microsoft)

Launcher oficial gratuito do Minecraft, que baixa e mantém as versões Java e Bedrock atualizadas depois da compra do jogo.

O Minecraft Launcher é o programa oficial que instala, atualiza e abre as versões Java e Bedrock do Minecraft no PC. Ele é gratuito, mas o jogo só roda numa conta que tenha a licença comprada — não existe versão gratuita do Java & Bedrock para PC. O launcher também deixa escolher versão, perfil de mods e servidor, e é por ele que o jogo recebe atualização. Compre uma vez e jogue nas duas versões, com suporte a servidor próprio e multijogador.

Requisitos

Windows 10/11, macOS ou Linux (64 bits); 4 GB de RAM (8 GB recomendados) e Java embutido no launcher. Conta Microsoft com a licença do jogo vinculada.
Antes de comprar: O launcher é grátis, mas sem a licença do jogo ele não abre o Minecraft — não confunda com o Education Edition, vendido à parte. O download sai da página oficial minecraft.net para Windows, macOS, Linux e servidores.
