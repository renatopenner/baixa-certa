DBeaver Community

por DBeaver Corp

Cliente SQL gratuito que conecta MySQL, PostgreSQL, SQL Server e outros bancos em uma única janela de trabalho.

Gerencia bancos relacionais e NoSQL com um só programa: MySQL, PostgreSQL, SQL Server, Oracle, SQLite, MongoDB e mais. Tem editor SQL com autocompletar, diagramas de tabelas, geração de dados e comparação de estruturas. O Java já vem embutido, então não é preciso instalar nada separado. Gratuito e de código aberto na edição Community.
